# Working templates: pre-build brief, dot-dash outline, delivery note

Copy these into the chat (never into the deliverable). They are the maker's
tools; the client page carries content words only.

## 1. Pre-build brief (fill before the first title is written)

```
Reader            : <name, role, what they decide after reading>
Reading mode      : live / sent ahead / board book / appendix / scored against a form
Document type     : <from document-types.md>  Length cap: <pages or slides>
Decision sought   : <one sentence>
Governing thought : <one falsifiable sentence with the key number>
Scope             : covers <…>; does not cover <…>
Evidence base     : <files, interviews, data, as-of dates>
Anchors available : <people, dates, amounts, project names, contract numbers>
Missing           : <numbers to find, who has them>
Company template? : yes <path> / no (use palette A/B/C from visual-system.md)
```

## 2. Dot-dash outline

Dots become titles. Dashes are the facts or exhibits under each. Each dot
carries an exhibit sketch, what data is in hand, and a confidence tag
(solid / likely / speculative). Keep it ugly: no colours, no alignment, so
the reviewer critiques the logic, not the polish.

```
S  <situation, one to three sentences the reader already accepts>
C  <what changed or what is at stake>
Q  <the one question>
A  <the answer, with the key number>

• <key line 1, full sentence with a number>            [exhibit: bar, 3 sites x cost/MW] [data: have] [solid]
  – <fact / source / date>
  – <fact / source / date>
• <key line 2>                                          [exhibit: waterfall 18 → 6 亿] [data: need DC Byte 2025Q1] [likely]
  – …
• <key line 3>
  – …
• Decision requested: <what>, owner <who>, by <date>; next 30 days: <a, b, c>
```

Read the dots aloud as one paragraph. If the paragraph does not argue, the
outline is not done. For anything over ten slides or with real stakes, show
the dots to the author before building.

## 3. Executive summary skeleton

```
<Governing thought as one sentence with the key number.>
<Framing line: period, scope, lens.>

<Key line 1, with number and so-what.>  Evidence: <fact, source>.
<Key line 2.>  Evidence: <…>.
<Key line 3.>  Evidence: <…>.
[<Key line 4 or 5 only if the logic needs it.>]

Decision requested: <what>, by <date>. Owner: <who>. Next 30 days: <a, b, c>.
(or: For information; no decision needed.)
```

Not bolded line by line (the reader asks why only that one). No structure
labels on the page. Every number traces to a body page. If it spills past
one page, the story is not sharp yet.

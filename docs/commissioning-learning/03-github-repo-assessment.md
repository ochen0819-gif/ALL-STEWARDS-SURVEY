# 附表：GitHub 仓库评估总表

本表汇总两轮检索中逐个打开阅读过的 125 个 GitHub 仓库。

**评分口径**：1–10 分。
- **质量**：内容深度与正确性。只有 README 或空壳的仓库不超过 3 分。
- **调试相关**：对学习数据中心调试管理（CxM）和调试代理（CxA）工作有多大帮助，包括 L1–L5 分级、OPR/BOD、调试计划、检查表、FPT/IST 脚本、FMEA、RACI。
- **3D 可复用**：对做电、水、冷动态讲解图有多大借鉴价值。

**一句话评价**：摘自代理阅读仓库后写的英文评估原文，未翻译。

**复核**：标“已复核”的仓库，由第二个代理重新打开核对过文件和在线站点。“有更正”表示复核后修改了原评价或分数。表中分数已是复核后的分数。

**使用提醒**
- 没有 LICENSE 文件的仓库，默认保留所有权利。只能学习思路，不要复制代码、文字或模型。
- 繁体中文站点多数由 AI 辅助生成，数字要回到标准原文核对。
- 本表只是评估，不是推荐顺序。推荐顺序见学习地图第 6 节和 3D 报告附录 A。

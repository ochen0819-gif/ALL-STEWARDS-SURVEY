# 匿名问卷调查系统 · Netlify 部署说明

## 目录结构
- `public/index.html` — 问卷 + 管理后台（单页应用）
- `netlify/functions/` — 云端接口（提交 / 管理员登录拉取 / 健康检查）
- `netlify.toml` — Netlify 配置
- `package.json` — 依赖声明（@netlify/blobs 云端存储）

## 部署方式（二选一）

### 方式一：GitHub + Netlify（推荐，改动自动上线）
1. 把本文件夹整体上传为一个 GitHub 仓库（目录结构保持不变）。
2. 登录 app.netlify.com → Add new project → Import an existing project → 选该仓库。
3. 构建设置不用改（netlify.toml 已配置好），直接 Deploy。
4. 部署完成得到 `https://xxx.netlify.app` 链接，发到微信即可使用。

### 方式二：Netlify CLI（命令行直接发布）
1. 装好 Node.js 后执行 `npm install -g netlify-cli`
2. 在本文件夹内执行 `netlify login`，再 `netlify init` 创建站点
3. 发布：`netlify deploy --prod`（Publish directory 填 `public`）

⚠️ 请勿使用网页版「拖拽上传」部署：拖拽不会安装依赖，云端接口会失效。

## 管理员账号
- 默认账号：`admin`　默认密码：`stewards2026`
- 密码在服务端校验，页面源码中不含密码。
- 修改方法：Netlify 站点 → Site configuration → Environment variables，
  新增 `ADMIN_USER` 与 `ADMIN_PASS` 两个变量，然后在 Deploys 页 Trigger deploy 重新部署即生效。
- 正式使用前务必修改默认密码。

## 数据与匿名性
- 数据保存在 Netlify Blobs（站点自带云存储，零配置，可在 Netlify 控制台 Blobs 页查看/删除）。
- 系统不记录填写者 IP、设备、姓名等任何身份信息，仅存答案与提交时间。
- 免费额度：函数每月 12.5 万次调用，问卷用途足够。

## 微信中使用
- 直接把链接发到微信群/私聊，手机点开即可作答。
- 如微信提示「非官方网页」，点「继续访问」即可；若被拦截，建议绑定自有域名。
- 管理后台导出 CSV / 打印报告时，请点微信右上角「···」→「在浏览器打开」后再操作。

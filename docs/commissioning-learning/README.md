ASHRAE Guideline 1.6P《Application of the Commissioning Process to Data Centers》是 ASHRAE 第一份专门讲数据中心调试的指南。它正在做首次公开评审，评审期到 **2026 年 11 月 16 日**结束。

评审期内注册免费的 ASHRAE 账号，就能在线阅读草稿。正式出版后要付费购买。

## 使用前要知道的局限

- **我们看不到你的网站。** 你的 GitHub 仓库里只有一个匿名问卷系统，没有那个调试学习网站。所以第二部分的建议是通用做法，第 2 刀教你先自己认出网站用的是哪种 3D 引擎。
- **L1–L5 不是法定分级。** 它是行业惯例，各家定义不同，每个项目以合同和调试计划为准。
- **数字分等级。** 报告里每个数值都标了来源等级和性质。标“二手”或“示例”的数值不能直接写进测试脚本或报价澄清函。
- **许可证。** 评估过的仓库里有 55 个没有 LICENSE 文件，默认保留所有权利。这些只能学思路，不能复制代码、文字或模型。
- **繁体中文站点。** ekcwilson-git 系列质量较高，但多为 AI 辅助生成，且部分取材于客户的保密文件，只能私下学习，不要转载。
- **链接检查结果。** 有些链接从我们的环境访问时返回 403。GitHub 网页链接返回 403 是检查环境的代理所致，这些仓库都已用 git 确认存在。知乎、ASHRAE、Uptime 等站点返回 403 是反爬限制。另有少数国内站点从海外访问超时，例如中国数据中心标准查询库 arcwei2060.site，在国内网络下应能打开。
